# Documentação do Projeto

## 07. Roadmap

Este documento apresenta a evolução planejada do projeto. Seu objetivo é
orientar o crescimento da aplicação sem comprometer o escopo do MVP.

------------------------------------------------------------------------

## MVP

Objetivo: entregar uma versão funcional e utilizável.

### Funcionalidades

-   Dashboard
-   Áreas
-   Listas
-   Tarefas
-   Checklist
-   Links
-   Visualização em Lista
-   Visualização em Cards
-   Banco de dados PostgreSQL
-   API REST
-   Deploy da aplicação

------------------------------------------------------------------------

## Versão 1.1

Melhorias de usabilidade e produtividade.

### Possíveis evoluções

-   Pesquisa de tarefas
-   Filtros avançados
-   Ordenação personalizada
-   Melhorias de interface
-   Atalhos de produtividade

------------------------------------------------------------------------

## Versão 2

Expansão das funcionalidades.

### Possíveis evoluções

-   Login e autenticação
-   Sincronização entre dispositivos
-   Compartilhamento de listas
-   Colaboração entre usuários
-   Notificações

------------------------------------------------------------------------

## Ideias Futuras

Estas funcionalidades poderão ser avaliadas futuramente:

-   Aplicativo mobile
-   PWA
-   Etiquetas
-   Temas personalizados
-   Integrações com serviços externos
-   Automações

------------------------------------------------------------------------

## Diretrizes

-   O MVP deve permanecer simples.
-   Novas funcionalidades devem ser avaliadas antes de entrarem no
    projeto.
-   A evolução deve ocorrer de forma incremental, preservando a
    organização e a qualidade do código.
